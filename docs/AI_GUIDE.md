# AI アシストでできること

文字PVメーカーの AI アシストの説明書です。AI を使わなくても、アプリのほかの機能はすべて使えます。

## はじめに：API キーを用意する

1. [Google AI Studio](https://aistudio.google.com/apikey) で Gemini の API キーを作ります。
2. アプリの右上の「AI」を押し、「使う AI と API キー」を開きます。
3. AI サービスは「Google Gemini」、モデルは「gemini-3.8-flash（既定）」のままで大丈夫です。
4. 「API キー」にキーを貼り付けます。すぐに確認が走り、「このキーで使えます」と出れば準備完了です。
   - 「キーを確認」でいつでも確かめ直せます。この確認では料金はかかりません。
   - ふだんは、タブを閉じるとキーが消えます。「この端末に記憶する」をオンにすると残ります。共用の PC ではオンにしないでください。

## 1. 歌詞の下ごしらえ

歌詞サイトなどから貼り付けた歌詞を、文字PV向けに整える案を出します。

| 提案すること | 例 |
|---|---|
| 歌詞ではない行を除く | 「作詞：〇〇」「[Verse]」「【サビ】」「×2」「歌詞をコピー」 |
| カットの区切り | 「夜明けの色を覚えてる」→「夜明けの色を / 覚えてる」 |
| 強調する語 | 意味の中心になる語を `*強調*` に |
| 特別な読み | 「本気」を「まじ」と歌うときなど、当て字の読み |

- 歌詞の言葉そのものは変えません。区切りや強調の記号を足すだけです。
- 出てきた案にチェックを入れて「選んだ変更を歌詞に反映」を押すと、歌詞の欄が書き換わります。

## 2. AI 演出3案

歌詞の意味を読み取って、見た目の方向性を3つ提案します。

- それぞれの案に、スタイル（配色と書体）・雰囲気・動きの強さ・配色・使わない演出・サビの行の見せ方が入っています。
- 歌詞の季節を読み取り、合わないモチーフ（夏の歌に雪、冬の歌に花火など）は使わないようにします。
- 「この案にする」で反映します。ほかの案に切り替えると、最初の状態から作り直します。
- 「曲を分析する」をしておくと、サビの位置や曲の雰囲気も使って提案します。

## 3. ひとこと修正

一文で頼むと、変更の一覧を作ります。使うものにチェックを入れて「選んだ変更を適用」を押します。

頼み方の例：

- サビをもっと派手に
- 全体を落ち着いた雰囲気に
- 2行目は縦書きにして
- 配色を夏っぽく
- グリッチを減らして
- 桜のモチーフは使わないで
- 最後の行にフラッシュを入れて

意味があいまいなときは、何も変えずに聞き返します。

## 4. 曲を使う（Gemini だけ・試験的）

読み込んだ曲の音声を Google Gemini に送って、次のことをします。使うには、パネルの「曲の音声を Google Gemini に送ることに同意する」にチェックを入れます。

| 機能 | すること | 反映のしかた |
|---|---|---|
| 曲から歌詞を書き起こす | 歌っている歌詞を聞き取り、行ごとの開始時刻を付けます | 歌詞の欄が置き換わります。時刻は行頭の `[分:秒]` になります |
| 歌詞のタイミングを曲に合わせる | 入力済みの歌詞の各行が、曲のどこで始まるかを探します | 行リストの開始時刻が変わります |
| 曲を分析する | イントロ・Aメロ・サビなどの区切り、盛り上がる所、雰囲気、テンポを調べます | プロジェクトに保存し、演出3案とひとこと修正で使います |

- 時刻は目安です。ずれていたら、行リストの秒数を直してください。
- 送ってよい曲（自分の曲や、権利者の許可がある曲）だけに使ってください。市販の曲などは、AI が書き起こしを断ることがあります。そのときは歌詞を自分で貼り、「歌詞のタイミングを曲に合わせる」を使ってください。
- 音声は 16 kHz のモノラルにしてから送ります。7分くらいまでの曲は1回の送信で済みます。それより長い曲は、音質を少し下げるか、アップロードしてから使います。

## 送るものと保存されるもの

- 送るもの：歌詞のテキスト、ひとこと修正の文、設定の数値。曲の音声は、「曲を使う」のボタンを押したときだけ送ります。
- 送り先：選んだ AI サービスだけです。ブラウザから直接送り、ほかのサーバーは通りません。
- キー：このブラウザにだけ保存します。プロジェクトのファイル（.json）には入りません。
- 曲の分析の結果（区切りの時刻など）は、プロジェクトに保存されます。

## 料金の目安

- 料金は AI サービスから請求されます。1回ごとに、使ったトークン数と金額の目安がパネルの下に出ます。
- gemini-3.8-flash で、40行の歌詞に下ごしらえ1回・3案1回・ひとこと修正3回を使って、約10円です（1ドル150円）。
- 曲を使う機能は、4分の曲で1回あたり数円です。
- 2027年からは Gemini 3.8 Flash の単価が上がる予定です。

## うまくいかないとき

| 表示 | すること |
|---|---|
| API キーが正しくないか、使えない状態です | キーを貼り直して「キーを確認」を押します |
| キーは有効ですが、このモデルは使えません | 「モデル」を変えます |
| 利用の上限に達しました | 少し待ってからやり直します |
| AI サービスが、この内容への回答を控えました | 歌詞や曲の内容で断られました。別の頼み方にするか、手で調整します |
| 問い合わせのあいだに歌詞が変わりました | 歌詞を変えずに、もう一度押します |
| 曲を使う機能は、Google Gemini を選んだときだけ使えます | AI サービスを Google Gemini にします |

## AI がしないこと

- 歌詞の言葉を書き換えること（書き起こしを除く）
- 確認なしに設定を変えること。どの機能も、一覧を見せてから反映します
- 曲を送ること（「曲を使う」を押したときを除く）
