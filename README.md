# 文字PVメーカー

歌詞から文字PV（リリックモーション動画）を作る、ブラウザだけで動くアプリです。

**▶ <https://momomonbi.github.io/moji-pv/>**（English: <https://momomonbi.github.io/moji-pv/en/>）

インストールも登録も要りません。AI を使わなくても、すべての機能が使えます。

## 使い方（3ステップ）

1. **歌詞を貼る** — ① 歌詞 に貼り付けるだけ。「サンプルで試す」でもすぐ始められます。
2. **おまかせ** — 再生バーの「おまかせ」（キーは R）を押すたびに、雰囲気・配色・動きがまとめて変わります。気に入るまで何度でもどうぞ。
3. **書き出し** — ④ 書き出し で形式と大きさを選んで「書き出す」。

歌詞の書き方は画面の「記法」で見られます。`/` でカットを分ける、`*言葉*` で強調、行末の `!` で見せ場、`[00:12.34]` で開始時刻（LRC）など。

## 細かく直したいとき

プレビューや歌詞をクリックすると、「詳細」の欄でその部分を直せます。場所は **作品全体 → 行 → カット → 要素**（文字・装飾・背景・カメラ・画面効果・切り替え）の順にたどれます。

- **自動 / 固定** — ふだんはすべて「自動」。自分で選んだ値は「固定」になり、おまかせや振り直しでも変わりません。「固定を外す」で自動に戻ります。
- **ロック** — 気に入った行はロックすると、その見た目のまま残ります。
- **見た目の履歴 ◀ ▶** — おまかせで試した見た目は再生バーの ◀ ▶ で行き来できます。前の案に戻るのも簡単です。
- 変更はすべて「元に戻す」で取り消せます。作品はブラウザに自動保存されます。

## 曲（任意）とタップ合わせ

曲がなくても作れます（長さは歌詞の量から決まります）。② 曲 で mp3・wav・m4a・ogg・flac を読み込むと、テンポを調べて動きの速さに生かします。「拍に合わせる」をオンにすると、自動で決まる行の開始を拍にそろえます。

- **タップで合わせる** — 曲を流しながら、行が始まるところでスペースを押すと、その行の開始時刻を記録します。
- 歌詞に `[00:12.34]` のような時刻（LRC）があれば、それに合わせます。

## 書き出し

| 形式 | 内容 |
|---|---|
| MP4 | 動画（音声も入れられます） |
| PNG連番 | 1フレーム1枚の PNG を ZIP にまとめたもの |
| 透過PNG | 背景が透明な PNG 連番 |

大きさは 720p〜2160p、なめらかさは 24 / 30 / 60 fps。画面の形は 16:9・9:16・1:1 ほか。

**背景の種類**: 通常 / グリーンバック / 黒（白文字） / 透明（= 透過PNG連番）。
透明な**動画ファイル**は、いまのブラウザでは作れません。ほかの映像に重ねたいときは、透過PNG か、動画アプリ用ならグリーンバックを使ってください。

MP4 の書き出しには、PC の Chrome か Edge をおすすめします（WebCodecs を使います）。

## AI アシスト（任意）

詳細の欄の「AI」タブから使えます。自分の API キーが必要です（既定は Google Gemini の **gemini-3.8-flash**）。

- **歌詞の下ごしらえ** — 歌詞でない行（作詞・［サビ］など）を外し、区切り・強調・読みを提案
- **演出を3案** — 歌詞の意味と季節に合う見た目を3つ。試写してから選べます
- **ひとこと修正** — 「サビをもっと派手に」のような一言で設定を変更
- **曲を使う**（Gemini のみ）— 同意したうえで曲を送り、書き起こし・タイミング合わせ・曲の分析

結果はまずチェック付きの一覧で出て、選んだものだけが反映されます（「元に戻す」1回で取り消し）。
送るのは歌詞のテキスト・指示・設定の数値だけ。曲の音声は、「曲を使う」で同意したときだけ送ります。
キーはこのブラウザの中にだけ保存され、選んだ AI サービスにだけ直接送られます。

くわしくは [docs/AI_GUIDE.md](docs/AI_GUIDE.md) へ。

## プライバシー

歌詞・曲・書き出しの処理は、すべてあなたのブラウザの中で行います。サーバーには何も送りません。
外と通信するのは、書体（Google Fonts）の読み込みと、AI アシストを使ったときの AI サービスとの通信だけです。

## 開発

Python 3.11 と Node 22 だけで動きます（npm / pip のパッケージは不要。ブラウザの試験だけ Playwright を使います）。

```
python3 build.py --check              # lint・層の決まり・モジュールの順番を確かめる（何も書かない）
node --test 'tests/node/*.test.js'    # Node の試験
python3 build.py --lab                # 試験用の tests/www/lab.html も作る
python3 build.py                      # index.html と en/index.html を作る
python3 tests/browser/ui_flows.py     # ブラウザの試験（tests/browser/*.py、Playwright）
python3 tests/build_test.py           # build.py の試験
```

ブラウザの試験は `PW_CHANNEL=chrome`（インストール済みの Chrome）か `PW_EXECUTABLE=/path/to/chromium` で動きます。
CI（`.github/workflows/ci.yml`）はこの順番で全部を実行し、コミットされた index.html / en/index.html がビルド結果と同じかも確かめます。
ページには CSP（スクリプトはハッシュで許可）が入っているので、index.html は手で直さず、必ず `build.py` で作り直してください。
