歌詞

  • 1行が1フレーズ。空行は少し間を空けます
  • 夜明けの色を/覚えてる … / でカットの切れ目を指定
  • *透明* … 強調（大きく・インパクト寄りの演出）
  • 行末の ! … フラッシュと揺れを入れる
  • 歌詞|ruby or note … 注釈レイアウトの小さな文字
  • [01:23.45]歌詞 … LRC のタイムスタンプをそのまま使用
  • # で始まる行 … コメント（無視）

    グリーンバック／ブラックバックにすると、白い文字と演出だけを単色の背景の上に描きます（背景の模様・紙の質感・粒子・周辺減光は入りません）。プレビューにもそのまま反映されます。グリーンバックは動画編集ソフトのクロマキーで、ブラックバックは「スクリーン」合成や輝度キーで抜いて、別の映像の上に重ねられます。

    AI アシスト

    使わなくても、ほかの機能はすべて使えます。できることの説明
    使う AI と API キー
    API キーを作る

    送るのは、歌詞のテキスト・ひとこと修正の文・設定の数値です。曲の音声は、「曲を使う」のボタンを押したときだけ送ります。キーは、選んだ AI サービスにだけ送ります。利用料は、そのサービスから請求されます。

    歌詞の下ごしらえ

    歌詞ではない行（作詞のクレジットや [Verse] など）を除く候補、カットの区切り、強調する語、特別な読みを提案します。

    AI 演出3案

    歌詞の意味から、スタイル・配色・動き・サビの見せ方を3案作ります。季節に合わないモチーフ（夏の歌に雪など）は使いません。

    曲の分析（サビの位置・雰囲気・テンポ）も使います。

    ひとこと修正

    曲を使う（Gemini だけ・試験的）

    読み込んだ曲の音声を Google Gemini に送って、歌詞の書き起こし・タイミング合わせ・曲の分析をします。時刻は目安です。ずれたら行リストで直してください。
